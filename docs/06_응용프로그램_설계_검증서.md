# 응용프로그램 설계 및 동작 검증서 (06_응용프로그램_설계_검증서.md)

## 1. 응용프로그램 아키텍처

본 프로그램은 콘솔 환경에서 동작하는 Python CLI 응용프로그램으로, 사용자가 번호 선택과 파라미터 입력을 통해 데이터베이스를 조회할 수 있도록 구성되었다.

```text
src/
├── db.py       # MySQL 연결 관리 및 SELECT 쿼리 실행 모듈
└── main.py     # 메뉴 라우팅, 입력값 유효성 검사, 표(Table) 포맷 출력
```

---

## 2. 모듈별 역할 및 구현 내용

### 2.1 `src/db.py`
- `get_connection()`: `pymysql.connect()`를 사용하여 MySQL Server 8.0 `subway_db`에 연결하는 커넥션 객체 생성 및 반환.

### 2.2 `src/main.py`
- **반복 실행 루프**: `while True` 루프를 통해 사용자가 0번(종료)을 선택할 때까지 메인 메뉴가 유지됨.
- **입력 정규화**:
  - `normalize_line()`: '2', '2호선', '02호선' 입력을 '2호선' 규격으로 자동 변환.
  - 날짜 미입력 시(엔터) 기본값(`2025-12-01` ~ `2025-12-07`) 매핑.
- **표 렌더링**: `tabulate` 라이브러리의 `fancy_grid` 포맷을 적용하여 터미널 표 형태로 정돈된 데이터 출력.

## 3. 기능별 동작 검증 결과

### 3.1 [기능 1] 빠른하차 위치 안내
- **테스트 조건**: 역명='서울역', 호선='1호선', 이동설비='엘리베이터'
- **실행 결과 화면**:
```text
╒════════╤════════╤════════════╤════════════╤════════╤══════════════╤═══════════════╤════════════════════════════╕
│  역명  │  호선  │  이동설비  │  운행방향  │  방면  │  하차 칸-문  │  설비 위치명  │       상세 위치 설명       │
╞════════╪════════╪════════════╪════════════╪════════╪══════════════╪═══════════════╪════════════════════════════╡
│ 서울역 │ 1호선  │ 엘리베이터 │    상행    │  시청  │     5-1      │ 서울역(1) B2  │ 시청 방면5-1, 남영 방면4-4 │
├────────┼────────┼────────────┼────────────┼────────┼──────────────┼───────────────┼────────────────────────────┤
│ 서울역 │ 1호선  │ 엘리베이터 │    하행    │  남영  │     4-4      │ 서울역(1) B2  │ 시청 방면5-1, 남영 방면4-4 │
╘════════╧════════╧════════════╧════════════╧════════╧══════════════╧═══════════════╧════════════════════════════╛
```
- **검증 결과**: 성공 (상행: 시청 방면 5-1, 하행: 남영 방면 4-4 하차 칸-문 및 설비 위치 일치)

### 3.2 [기능 2] 시간대별 혼잡도 및 한산한 시간대 추천
- **테스트 조건**: 역명='강남', 호선='2호선', 요일='평일', 운행방향='내선'
- **실행 결과 요약**:
  - 05:30부터 24:30까지 39개 구간의 혼잡도(%)가 시간순 정렬 출력됨.
  - 최저 혼잡 시간대 TOP 3: 24:30 (12.04%), 24:00 (13.62%), 05:30 (22.18%) 추출.
  - 최고 혼잡 시간대: 18:00 (132.13%) 식별 및 주의 안내 표기.
- **검증 결과**: 성공 (시간대별 혼잡도 순차 출력 및 최저/최고 시간대 추출 일치)

## 4. 예외 처리 및 프로세스 관리 검증

1. **미등록 역명 입력 시**: 비정상 종료 없이 "일치하는 역 정보가 없습니다" 안내 후 메인 메뉴 복귀.
2. **호선 번호 입력 오류 시**: 1~8호선 범위 재입력 안내.
3. **종료 선택 시**: '0' 입력 시 "프로그램을 종료합니다" 출력 후 프로세스 정상 종료(`exit code 0`).
