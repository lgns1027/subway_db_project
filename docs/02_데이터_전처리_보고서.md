# 데이터 수집 및 전처리 보고서 (02_데이터_전처리_보고서.md)

## 1. 공개 데이터 수집 개요

서울교통공사 1~8호선을 대상으로 총 4종의 공공데이터를 수집하여 데이터베이스 구축에 활용하였다.

| 데이터셋 | 출처 | 제공 형식 | 원본 규모 | 주요 항목 |
| :--- | :--- | :---: | :---: | :--- |
| **역 기준표** | 서울 열린데이터광장 (OA-121) | OpenAPI | 277건 (1~8호선) | STATION_CD, STATION_NM, LINE_NUM, FR_CODE |
| **빠른하차정보** | 공공데이터포털 | OpenAPI | 2,358건 | 관리번호, 호선, 역코드, 칸-문 번호, 연결설비, 위치명 |
| **지하철 혼잡도정보** | 공공데이터포털 | XLSX | 3개 시트 (평일/토/일) | 호선, 역번호, 역명, 상하구분, 30분 단위 39개 시간대 열 |
| **역별 시간대별 승하차인원** | 공공데이터포털 | CSV | 2025년 1년치 | 수송일자, 호선, 역번호, 역명, 승하차구분, 시간대별 인원 열 |

---

## 2. 데이터 전처리 파이프라인

데이터 전처리는 Python 스크립트 3단계 파이프라인으로 구성되어 수행되었다:
1. `01_collect_api.py`: 역 기준표 OpenAPI 호출 및 `station_master.csv` 생성
2. `01b_collect_fast_exit.py`: 빠른하차 OpenAPI 호출 및 `fast_exit.csv` 생성
3. `02_preprocess.py`: 비정규형 구조 정규화, 시간대 축 변환, 역코드 규격 통일 및 정제본 생성

## 3. 세부 전처리 및 정제 내역

### 3.1 시간대 열의 행 변환 (Unpivot / Melt)
- **대상**: 혼잡도정보(xlsx), 승하차인원(csv)
- **내용**: 원본 데이터는 시간대(05:30 ~ 24:30)가 다수의 열(Column)로 분할된 구조였음. 이를 `(시간대, 혼잡도)`, `(시간대, 승차인원, 하차인원)`의 튜플 형태 행(Row)으로 변환하여 제1정규형(1NF)을 만족하도록 재구성함.

### 3.2 승차/하차 행 병합
- **내용**: 승하차 원본은 동일 역·일자·시간대에 대해 '승차' 레코드와 '하차' 레코드가 분리되어 있었음. 이를 하나의 행에 `승차인원`, `하차인원` 열을 갖는 단일 레코드로 통합 피벗함.

### 3.3 승하차 데이터 기간 범위 설정 (2025년 12월 1개월)
- **선정 기준**: 1년 전체 데이터(약 200만 건 이상) 중 혼잡도 데이터 기준 시점에 맞추어 2025년 12월 1개월치(169,260건)를 대상으로 선정함. 해당 기간은 평일 및 주말 승하차 패턴을 포함하고 있음.

### 3.4 전철역코드(`STATION_CD`) 규격 통일
- **내용**: 데이터셋별로 역코드 자릿수 표기에 차이가 존재함 (예: 빠른하차 `0150`, 혼잡도 `150`, 역 기준표 `0150`).
- **조치**: 숫자 앞자리에 0을 패딩하는 `zfill(4)` 함수를 적용하여 모든 데이터의 `STATION_CD`를 4자리 고정 문자열로 통일함.

### 3.5 미매칭 결측값(성수E, 응암S) 351건 제외
- **원인**: 차량기지 입출고 및 지선 순환 구간으로 역 기준표에 매칭되지 않아 `STATION_CD`가 공백으로 남음.
- **영향**: 외래키 무결성 위반 및 데이터 타입 오류 유발.
- **조치**: `congestion_long.csv`에서 역코드가 결측된 351건을 필터링하여 정제본 `congestion_clean.csv` 생성.

### 3.6 지선 분기역 혼잡도 중복 585쌍(1,170행) 평균 집계 통합
- **원인**: 2호선 성수역(본선 순환 211 vs 지선 분기 9002), 신도림역, 5호선 강동역 등에서 동일 복합 키 `(STATION_CD, 요일구분, 상하구분, 시간대)`를 가진 행이 2건씩 존재함.
- **영향**: 물리 스키마의 `UNIQUE(station_cd, day_type, direction, time_start)` 제약조건 위반 발생.
- **조치**: 동일 키에 대해 혼잡도 값을 평균(`AVG`)하여 단일 레코드로 집계함 (65,169행 $\rightarrow$ 64,233행, 중복 0건).
