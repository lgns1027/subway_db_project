## 2. 프로젝트 소스 및 데이터 파일 구성

```text
기말/
├── schema.sql               # 데이터베이스 7개 테이블 DDL
├── load_data.py             # CSV 데이터 MySQL 적재 스크립트
├── queries.sql              # 핵심 조회 SQL 쿼리 모음
├── erd1.png / erd2.png      # ERD 이미지 파일
├── src/
│   ├── db.py                # MySQL 연결 모듈
│   └── main.py              # CLI 응용프로그램 메인
└── 데이터 전처리/           # 원본 데이터, 정제 스크립트, clean CSV
```
