# 데이터베이스 설계서 (03_데이터베이스_설계서.md)

## 1. 데이터베이스 설계 개요

본 설계는 서울교통공사 1~8호선 공공데이터의 중복을 최소화하고 관계형 무결성을 보장하기 위해 수행되었다. 하나의 물리적 역이 여러 노선에 속하는 환승역의 다대다(M:N) 관계를 정규화하여 1:N 관계로 해소하고, 이동 편의시설, 열차 혼잡도, 승하차 통계를 연계하도록 7개 릴레이션으로 구성하였다.

## 2. 개념적 모델링 (개체 및 관계)

### 2.1 주요 개체 (Entity)
1. **LINE (호선)**: 지하철 노선 정보 (1호선 ~ 8호선)
2. **STATION (역)**: 물리적 역명 기준의 고유 역 개체 (환승역 통합 개체)
3. **LINE_STATION (노선별 역)**: 특정 호선에 속한 역 개체 (STATION과 LINE의 교차 개체)
4. **FACILITY_TYPE (이동설비유형)**: 엘리베이터, 에스컬레이터, 계단 등 편의시설 분류
5. **FAST_EXIT (빠른하차)**: 특정 역·방향별 이동설비 연결 하차 칸-문 정보
6. **CONGESTION (혼잡도)**: 특정 역·요일·방향·시간대별 열차 혼잡도
7. **RIDERSHIP (승하차인원)**: 특정 역·일자·시간대별 승하차 통계

### 2.2 개체 간 관계 (Relationship)
- `STATION` : `LINE_STATION` = 1 : N (하나의 역은 여러 노선에 속할 수 있음)
- `LINE` : `LINE_STATION` = 1 : N (하나의 노선은 여러 역을 포함함)
- `LINE_STATION` : `FAST_EXIT` = 1 : N (하나의 노선별 역은 여러 하차 위치 정보를 가짐)
- `FACILITY_TYPE` : `FAST_EXIT` = 1 : N (하나의 설비유형은 여러 하차 위치에 매핑됨)
- `LINE_STATION` : `CONGESTION` = 1 : N (하나의 노선별 역은 여러 시간대의 혼잡도를 가짐)
- `LINE_STATION` : `RIDERSHIP` = 1 : N (하나의 노선별 역은 여러 일자·시간대의 승하차 기록을 가짐)

## 3. 논리적 설계 (릴레이션 스키마)

1. `LINE` (**`line_code`**, `line_name`)
2. `STATION` (**`station_id`**, `station_name`)
3. `LINE_STATION` (**`station_cd`**, `station_id`*, `line_code`*, `source_station_name`, `external_code`)
   - FK: `station_id` REFERENCES `STATION(station_id)`
   - FK: `line_code` REFERENCES `LINE(line_code)`
   - UNIQUE: (`station_id`, `line_code`)
4. `FACILITY_TYPE` (**`facility_type_id`**, `facility_type_name`)
5. `FAST_EXIT` (**`management_no`**, `station_cd`*, `facility_type_id`*, `reference_date`, `direction`, `destination_info`, `car_door_no`, `facility_no`, `elevator_no`, `location_name`, `facility_location`)
   - FK: `station_cd` REFERENCES `LINE_STATION(station_cd)`
   - FK: `facility_type_id` REFERENCES `FACILITY_TYPE(facility_type_id)`
6. `CONGESTION` (**`congestion_id`**, `station_cd`*, `day_type`, `direction`, `time_start`, `congestion_rate`)
   - FK: `station_cd` REFERENCES `LINE_STATION(station_cd)`
   - UNIQUE: (`station_cd`, `day_type`, `direction`, `time_start`)
7. `RIDERSHIP` (**`station_cd`***, **`transport_date`**, **`time_slot`**, `boarding_count`, `alighting_count`)
   - FK: `station_cd` REFERENCES `LINE_STATION(station_cd)`

*(굵은 글씨: 기본키 PK, *: 외래키 FK)*

## 4. 물리적 설계 (테이블 정의서)

### 4.1 LINE (호선 마스터)
| 컬럼명 | 데이터 타입 | 제약조건 | 설명 |
| :--- | :--- | :---: | :--- |
| `line_code` | VARCHAR(10) | PK | 호선코드 ('01호선', '02호선' 등) |
| `line_name` | VARCHAR(50) | UK, NOT NULL | 호선명 ('1호선', '2호선' 등) |

### 4.2 STATION (통합 역 마스터)
| 컬럼명 | 데이터 타입 | 제약조건 | 설명 |
| :--- | :--- | :---: | :--- |
| `station_id` | BIGINT | PK, AUTO_INC | 통합 역 고유 식별자 |
| `station_name` | VARCHAR(100) | NOT NULL, INDEX | 대표 역명 ('시청', '서울역' 등) |

### 4.3 LINE_STATION (노선별 역)
| 컬럼명 | 데이터 타입 | 제약조건 | 설명 |
| :--- | :--- | :---: | :--- |
| `station_cd` | CHAR(4) | PK | 전철역코드 ('0150', '0201' 등) |
| `station_id` | BIGINT | FK, NOT NULL | 통합 역 ID |
| `line_code` | VARCHAR(10) | FK, NOT NULL | 호선코드 |
| `source_station_name` | VARCHAR(100) | NOT NULL | 노선별 역명 |
| `external_code` | VARCHAR(20) | NULL | 외부 역번호 (FR_CODE) |

### 4.4 FACILITY_TYPE (이동설비유형)
| 컬럼명 | 데이터 타입 | 제약조건 | 설명 |
| :--- | :--- | :---: | :--- |
| `facility_type_id` | BIGINT | PK, AUTO_INC | 설비유형 고유 식별자 |
| `facility_type_name` | VARCHAR(50) | UK, NOT NULL | 설비유형명 ('엘리베이터', '계단' 등) |

### 4.5 FAST_EXIT (빠른하차 정보)
| 컬럼명 | 데이터 타입 | 제약조건 | 설명 |
| :--- | :--- | :---: | :--- |
| `management_no` | VARCHAR(50) | PK | 관리번호 (식별자) |
| `station_cd` | CHAR(4) | FK, NOT NULL | 전철역코드 |
| `facility_type_id` | BIGINT | FK, NOT NULL | 설비유형 ID |
| `reference_date` | DATE | NULL | 기준일자 |
| `direction` | VARCHAR(20) | NULL | 상하행 구분 ('상행', '하행') |
| `destination_info` | VARCHAR(100) | NULL | 방면(행선지) |
| `car_door_no` | VARCHAR(20) | NOT NULL | 하차 칸-문 번호 ('4-4' 등) |
| `facility_no` | VARCHAR(50) | NULL | 시설번호 |
| `elevator_no` | VARCHAR(50) | NULL | 승강기번호 |
| `location_name` | VARCHAR(100) | NULL | 위치명 |
| `facility_location` | VARCHAR(255) | NULL | 설비 위치 상세 설명 |

### 4.6 CONGESTION (열차 혼잡도)
| 컬럼명 | 데이터 타입 | 제약조건 | 설명 |
| :--- | :--- | :---: | :--- |
| `congestion_id` | BIGINT | PK, AUTO_INC | 혼잡도 고유 식별자 |
| `station_cd` | CHAR(4) | FK, NOT NULL | 전철역코드 |
| `day_type` | VARCHAR(20) | NOT NULL | 요일구분 ('평일', '토요일', '일요일') |
| `direction` | VARCHAR(20) | NOT NULL | 상하구분 ('상선', '하선', '내선', '외선') |
| `time_start` | TIME | NOT NULL | 시간대 시작시각 ('05:30:00' 등) |
| `congestion_rate` | DECIMAL(5, 2) | NOT NULL | 혼잡도 퍼센트 (%) |

### 4.7 RIDERSHIP (시간대별 승하차 인원)
| 컬럼명 | 데이터 타입 | 제약조건 | 설명 |
| :--- | :--- | :---: | :--- |
| `station_cd` | CHAR(4) | PK, FK | 전철역코드 |
| `transport_date` | DATE | PK | 수송일자 |
| `time_slot` | VARCHAR(20) | PK | 시간대 구분 ('06-07', '07-08' 등) |
| `boarding_count` | INT | NOT NULL, DEFAULT 0 | 승차인원 합계 |
| `alighting_count` | INT | NOT NULL, DEFAULT 0 | 하차인원 합계 |

## 5. 원본 구조와 최종 설계 비교 및 재설계 근거

| 항목 | 원본 공공데이터 구조 | 최종 설계 구조 | 재설계 근거 |
| :--- | :--- | :--- | :--- |
| **환승역 구조** | 역명과 호선이 각 데이터마다 단순 문자열로 중복 나열됨 | `STATION`과 `LINE_STATION`으로 분리하여 1:N 정규화 | 환승역의 다대다 관계 해소, 특정 역의 전체 경유 노선 검색 지원, 역명 변경 시 단일 지점 수정 가능 |
| **시간대 혼잡도** | 30분 단위 시간대가 39개 열(Column)로 분할됨 | `CONGESTION` 테이블의 `(time_start, congestion_rate)` 행(Row)으로 정규화 | 제1정규형(1NF) 만족, SQL 집계(`AVG`, `MAX`) 및 시간대 정렬 지원 |
| **승하차 데이터** | 동일 역·일시의 승차와 하차가 별도 행으로 분리, 시간대 열 분할 | 일자·시간대 복합키 행에 `승차인원`, `하차인원` 병합 | 레코드 중복 제거, 승·하차 합산 및 순위 연산 처리 단순화 |
| **편의시설 유형** | 설비명이 문자열로 반복 저장됨 | `FACILITY_TYPE` 마스터 분리 및 외래키 참조 | 설비명 입력 오류 방지 및 참조 무결성 확보 |
