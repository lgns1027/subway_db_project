# 서울 지하철 하차 동선 및 이용 현황 조회 시스템

교통약자와 일반 승객을 위해 서울교통공사 1~8호선 데이터를 기반으로 구축한 MySQL 관계형 데이터베이스 연동 조회 응용프로그램입니다.

---

## 1. 실행 환경

- **OS**: Windows 10 / 11
- **DBMS**: MySQL Server 8.0 (포트: 3306)
- **Python**: Python 3.8 이상
- **사용 라이브러리**: `pymysql`, `tabulate`, `pandas`, `openpyxl`, `flask`

## 3. 설치 및 데이터베이스 복원

### 1단계: 파이썬 라이브러리 설치
터미널에서 아래 명령어를 실행하여 라이브러리를 설치합니다:
```bash
pip install pymysql tabulate pandas openpyxl flask
```

### 2단계: 데이터베이스 복원
명령 프롬프트에서 아래 명령어를 실행하면 데이터베이스(`subway_db`), 7개 테이블, 236,140건의 데이터가 한 번에 복원됩니다:
```bash
mysql -u root -p < 4_데이터베이스_SQL/subway_db_data.sql
```
*(또는 MySQL Workbench에서 `4_데이터베이스_SQL/subway_db_data.sql` 파일을 열어 실행)*

> **참고**: 빈 테이블 구조만 생성한 뒤 `load_data.py`로 CSV 데이터를 직접 적재하려면, `4_데이터베이스_SQL/subway_db.sql`의 테이블 생성문을 먼저 실행한 후 `3_소스코드` 폴더에서 `python load_data.py`를 실행합니다.

### 3단계: MySQL 연결 설정
`3_소스코드/src/db.py` 파일을 열어 본인의 MySQL 환경에 맞게 접속 정보를 입력합니다 (개인 비밀번호는 제출 시 제외되어 있습니다):

```python
# 3_소스코드/src/db.py
host = "localhost"
port = 3306
database = "subway_db"
username = "root"
password = "본인_MySQL_비밀번호"
```

## 4. 응용프로그램 실행 방법

`3_소스코드` 폴더로 이동하여 웹 방식 또는 터미널 방식 중 선택해 실행합니다.

### 방법 1. 웹 브라우저 실행
```bash
cd 3_소스코드
python app.py
```
1. 위 명령어를 실행하면 웹 서버가 구동됩니다.
2. 웹 브라우저에서 `http://localhost:5000` 주소로 접속합니다.
3. 상단 메뉴(1~6번)를 클릭하고 조건을 선택한 뒤 **[조회하기]**를 누르면 결과가 출력됩니다.

### 방법 2. 터미널 실행
```bash
cd 3_소스코드
python src/main.py
```
1. 화면에 표시되는 메뉴 번호(1~6)를 선택합니다.
2. 안내에 따라 역명과 호선 등을 입력하면 표 형태로 결과가 출력됩니다.
3. `0`번을 입력하면 종료됩니다.

## 5. 조회 기능 목록

1. **빠른하차 위치 안내**: 역명, 호선, 설비 종류(엘리베이터/에스컬레이터/계단)를 지정하여 하차 칸-문 번호 및 설비 위치 조회
2. **시간대별 열차 혼잡도 조회**: 역명, 호선, 요일, 운행방향별 30분 단위 혼잡도 및 최저/최고 혼잡 시간대 안내
3. **노선 및 기간별 역 승하차 이용객 집계**: 호선 및 날짜 범위를 지정하여 역별 승차/하차 합계 및 전체 이용객 순위 집계
4. **환승역 정보 조회**: 역명 입력 시 해당 역을 경유하는 모든 노선 목록 및 전철역코드 조회
5. **노선별 이동설비 설치 현황**: 특정 노선 내 역별 엘리베이터 연결 하차 위치 수 집계
6. **특정 시간대 노선 내 혼잡 역 순위**: 호선, 요일, 시간대를 지정하여 혼잡도가 높은 상위 10개 역 순위 조회
