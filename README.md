# 서울 지하철 하차 동선 및 이용 현황 조회 시스템 (README.md)

교통약자(휠체어, 유모차 이용자 등)와 일반 승객을 위해 서울교통공사 1~8호선 데이터를 기반으로 구축한 MySQL 관계형 데이터베이스 연동 조회 응용프로그램입니다.

---

## 1. 실행 환경

- **OS**: Windows 10 / 11
- **DBMS**: MySQL Server 8.0 (포트: 3306)
- **Python**: Python 3.8 이상
- **사용 라이브러리**: `pymysql`, `tabulate`, `pandas`, `openpyxl`, `flask`

## 3. 설치 및 데이터베이스 구축 (최초 1회 실행)

### 1단계: 파이썬 라이브러리 설치
터미널(PowerShell 또는 CMD)에서 아래 명령어를 실행하여 필요한 라이브러리를 설치합니다:
```bash
pip install pymysql tabulate pandas openpyxl flask
```

### 2단계: 데이터베이스 및 테이블 생성 (DDL)
MySQL Workbench에서 `4_데이터베이스_SQL/subway_db.sql` 파일을 열고 **번개 모양(Execute)** 아이콘을 클릭하여 데이터베이스(`subway_db`)와 7개 테이블을 생성합니다.  
(또는 명령 프롬프트에서 아래 명령어 실행)
```bash
mysql -u root -p < 4_데이터베이스_SQL/subway_db.sql
```

### 3단계: 공공데이터 적재
`3_소스코드` 폴더로 이동한 뒤, 아래 명령어를 실행하여 정제된 CSV 데이터를 MySQL에 적재합니다 (총 236,140건):
```bash
cd 3_소스코드
python load_data.py
```

## 4. 응용프로그램 실행 방법

본 시스템은 **웹(Flask)** 방식과 **터미널 콘솔(CLI)** 방식을 지원합니다. (`3_소스코드` 폴더 내에서 실행)

### 방법 1. 웹 브라우저 실행 (Flask 웹 방식)
```bash
cd 3_소스코드
python app.py
```
1. 위 명령어를 실행하면 로컬 웹 서버가 구동됩니다.
2. 웹 브라우저(Chrome 등)를 열고 **`http://localhost:5000`** 주소로 접속합니다.
3. 상단 메뉴(1~6번)를 클릭하고, 조건(역명, 호선 등)을 선택한 뒤 **[조회하기]**를 누르면 표 형태로 결과가 출력됩니다.

### 방법 2. 터미널 콘솔 실행 (CLI 방식)
```bash
cd 3_소스코드
python src/main.py
```
1. 터미널 화면에 표시되는 메뉴 번호(1~6)를 선택합니다.
2. 안내에 따라 역명과 호선 등을 입력하면 콘솔 표 형태로 결과가 출력됩니다.
3. `0`번을 입력하면 프로그램이 종료됩니다.

## 5. 조회 기능 목록 (6종)

1. **빠른하차 위치 안내**: 역명, 호선, 설비 종류(엘리베이터/에스컬레이터/계단)를 지정하여 하차 칸-문 번호 및 설비 위치 조회 (5개 테이블 JOIN)
2. **시간대별 열차 혼잡도 조회**: 역명, 호선, 요일, 운행방향별 30분 단위 혼잡도(%) 및 최저/최고 혼잡 시간대 안내
3. **노선 및 기간별 역 승하차 이용객 집계**: 호선 및 날짜 범위를 지정하여 역별 승차/하차 합계 및 전체 이용객 순위 집계 (`SUM`, `GROUP BY`)
4. **환승역 정보 조회**: 역명 입력 시 해당 역을 경유하는 모든 노선 목록 및 전철역코드 조회 (M:N 교차 릴레이션 활용)
5. **노선별 이동설비(엘리베이터) 설치 현황**: 특정 노선 내 역별 엘리베이터 연결 하차 위치 수 집계 (`COUNT`, `GROUP BY`)
6. **특정 시간대 노선 내 혼잡 역 순위**: 호선, 요일, 시간대를 지정하여 혼잡도가 높은 상위 10개 역 순위 조회 (`ORDER BY DESC LIMIT 10`)

## 6. DB 접속 환경 설정 변경 안내

MySQL 서버의 비밀번호나 접속 정보가 기본값(`root` / `0000`)과 다를 경우, **`3_소스코드/src/db.py` 파일의 접속 변수만 변경**하시면 모든 프로그램(`app.py`, `src/main.py`, `load_data.py`)에 적용됩니다:

```python
# 3_소스코드/src/db.py
host = "localhost"
port = 3306
database = "subway_db"
username = "root"
password = "본인_MySQL_비밀번호"
```
